## 추가 지적과 디자인

- v104: 사용자 요청에 따라 실제 기록이 있는 끼니 칸에 옅은 파란색을 누적 표시한다. 인접한 기록은 이어지지만 비어 있는 중간 끼니는 채우지 않는다. 날짜 변경 시 갱신하며 간식·끼니 없음도 표시하되 여러 장 저장 규칙은 유지한다.
- v104: 스탬프 7종의 선택은 파란 바탕·안쪽 테두리로 강조한다. 버튼 전체가 축소되는 효과와 이전 가로 스크롤 처리 제거. 모양/포즈 선택 시 도장 알파는 1을 유지하며 작은 크기 변화만 준다. 빠른 연속 선택에서 이전 효과는 취소한다. 처음 사진을 여는 도장 효과는 유지.
- 알림은 작고 옅은 도장 라벨, 32px 잉크 얼굴과 일정한 간격. 짧은 문구에 고정 빈 칸을 두지 않고 긴 문장은 자르지 않는다. 문장 길이에 따라 3~6.5초 표시한다.
- v103: 편집 화면 안내는 끼니 선택 아래의 일정한 두 줄 공간에 표시한다. 상단 도장 라벨은 띄우지 않아 사진과 겹치지 않는다. 다른 화면의 알림과 당겨서 새로고침 알약은 유지한다.
- 다른 날 사진을 달력 칸에 넣으면 조정된 날짜와 시각을 안내한다.
- v103: 끼니 막대의 작은 점·누적 파란 채움 제거. 고른 칸만 강조한다. 이미 남긴 끼니는 실제 사진 미리보기와 ‘점심 사진이 있어요’처럼 명시하고 완료 버튼을 ‘사진 교체’로 바꾼다. 자동으로 다른 끼니에 저장하지 않는다.
- v103: 교체 취소 시 추가 알림 없이 편집 상태를 유지한다. 날짜·끼니 변경 시 미리보기와 버튼 문구를 함께 갱신한다. 저장 오류·진행 안내도 같은 영역에 표시하고, 저장 중 안내 영역은 화면 읽기에서 제외하지 않는다.
- 완료 후에도 새 기록이 보이도록 필터 처리를 즉시 저장과 통일한다.
- 이미 찍은 끼니의 시작 화면은 다시 찍으라는 문구를 쓰지 않는다. 삭제 뒤에는 완료 알림을 준다.
- 앨범 오늘 카드: 아침·점심·저녁 각 30문구. 같은 화면에서 문구가 흔들리지 않고, 다음 실행에서는 직전 문구를 피한다(v101).

## 의도적으로 유지한 규칙

- 자동 끼니 시간대(아침 05–11, 점심 11–15, 저녁 17–22, 나머지 간식)는 사용자 동작 규칙이므로 변경하지 않았다. 다른 끼니로 남기고 싶을 때는 편집 막대에서 선택한다.
- 같은 날 다른 시각 사진을 교체하면 선택한 끼니와 새 사진의 촬영 시각을 유지한다. 다른 날 사진을 넣을 때만 정해 둔 시각 보정 규칙을 적용한다.
- 달력의 찬 칸은 확인창 없이 교체, 미완료 도장은 0끼·2끼를 구별하지 않음, 저장 후 끼니 변경 불가, 트레이너 공유 기능 없음은 기존 사용자 결정 그대로다.
- 기존 원본 삭제는 실제 사진 손실 위험 때문에 하지 않았다. 이번 저장 공간 개선은 새 파일과 미리보기·캐시에 적용한다.
