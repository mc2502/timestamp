# TimeStamp

식단 사진을 찍으면 날짜, 요일, 시각이 스탬프로 함께 찍히고, 그 사진을 트레이너에게 보내는 웹앱이에요.
iPhone 17(402 × 874) 기준으로 만들었고, 디자인은 PT Note 디자인 시스템을 그대로 따라요.

## 할 수 있는 것

탭은 **앨범 · (카메라) · 달력** 세 개이고, 설정은 앨범 오른쪽 위 톱니 버튼에 있어요. 가운데 카메라를 누르면 바로 찍고, 길게 누르면 버튼이 톡 튀며 바로 위에 앨범을 든 그날의 캐릭터 버튼이 떠요(손을 뗀 뒤 눌러서 골라요. 아이폰 웹앱은 진동 · 끌어서 놓기로 고르기를 지원하지 않아요).

- **앨범**: 큰 제목 아래 끼니 세그먼트(전체·아침·점심·저녁·간식), 앨범에서 사진 고르기 버튼, 설정. 그 아래 오늘 카드(작은 오둥이 · 퍼펭이 + 지금 끼니 한 줄, 보여 주기만)와 날짜별 3열 사진. 사진을 누르면 크게 보기(사진을 길게 누르면 아이폰 메뉴의 ‘사진 앱에 저장’), 바꾸기, 지우기.
- **가운데 카메라 버튼**: 아이폰 기본 카메라가 바로 열려요. 찍어 둔 사진은 앨범 탭 위의 사진 버튼으로 골라요.
- **스탬프 화면**: 위는 사진, 아래는 흰 패널 하나. 스크롤 없이 한 화면에 들어와요.
  - 정사각형으로 맞추기: 끌어서 옮기고, 두 손가락으로 키우거나 줄여요. 줄이면 사진 전체가 들어오고 남는 곳은 같은 사진을 흐리게 깔아요. 오른쪽 아래 버튼이나 두 번 톡으로 꽉 채우기 ↔ 사진 전체, ‘원래대로’로 되돌리기
  - 스탬프 7종을 이름 칩으로 골라요: 오둥이 · 퍼펭이(기본) · 기본 · 캡슐 · 혼합 · 크게 · 필름 (로고 없음)
  - 오둥이 · 퍼펭이: 왼쪽 아래 모서리에 걸쳐 찍힌 고무 도장(가장자리가 살짝 울퉁불퉁한 원판 + 잉크 고리, 원의 일부는 사진 밖, 날짜 · 시각 · 끼니는 보이는 쪽에), 도장 앞에 살짝 겹쳐 붙은 캐릭터(사진마다 다른 모습). 캐릭터는 끌어서 사진 어디로든 옮길 수 있고, 톡 누르면 다른 포즈, ‘원래대로’면 다시 도장 옆으로
  - 아래 조작부는 줄마다 다른 생김새: 스탬프는 작은 그림 타일 일곱 개 / 식사는 알약 하나(흰 손잡이) / 촬영 시각 ⌄ · 글자색 점은 글자 그대로 / 아래 두 버튼: 앨범 저장(옅은 회색 — 아이폰 공유 화면의 ‘이미지 저장’으로 사진 앱에 넣고 앱에도 남겨요) · 완료(옅은 청색 — 앱에만 남겨요). 위의 X는 남기지 않고 닫아요. 같은 끼니 사진이 이미 있으면 바꿀지 묻고, 취소하면 스탬프 화면에 그대로 있어요. 나중에 사진 앱에 넣고 싶으면 사진 보기에서 사진을 길게 눌러 ‘사진 앱에 저장’.
  - 글자색 흰색 · 하늘색 · 민트(오둥이가 든 책 색) (필름은 주황 고정)
  - 촬영 시각: 사진에 저장된 시각(EXIF)을 먼저 쓰고, 카메라로 바로 찍으면 지금 시각. 앨범 사진에 시각이 없으면 알려 줘요. 눌러서 고칠 수 있어요.
  - 식사: 시간대로 골라 두고, 끼니 이름이 든 막대에서 흰 손잡이를 끌거나 이름을 눌러서 바꿔요(아침 · 점심 · 저녁 · 간식 · 없음). 혼합 스탬프와 캐릭터 도장에 찍히고, 앨범에서 끼니별로 볼 때 써요.
- **달력**: 아침 · 점심 · 저녁 끼니 체크. 스크롤 없이 한 화면에(6주짜리 달도).
  - 달력 칸: 오늘은 점 세 개(남긴 끼니만 하늘색), 세 끼를 다 채운 날은 오둥이 · 퍼펭이 잉크 도장(표정 3종씩, 날짜마다 살짝 기울어 찍힘). 11월 1일부터 어제까지 세 끼를 다 못 채운 날은 회색 ‘못 채운 날’ 도장(오둥이 · 퍼펭이 아쉬움 · 배고픔, 날짜마다 정해진 캐릭터의 두 표정을 번갈아). 위에 이번 달 도장 수와 ‘N일 연속’.
  - 밥상 카드: 고른 날의 캐릭터(빈 그릇 → 마지막으로 먹은 끼니 → 배부름)와 세 칸. 사진이 있으면 체크, 없으면 빈 그릇 그림(지난날은 흐리게). 그림은 그대로이고, 칸을 누르면 빈 칸은 그 날 그 끼니 사진 올리기, 사진 칸은 새 사진으로 바꾸기(누른 순간에만 옅은 테두리). 스탬프 화면 없이 그 칸에 바로 들어가요(스탬프는 마지막에 쓴 모양, 있던 사진은 앱에서만 빠짐). 그 날 사진이 아니면 그 날의 끼니 시각(아침 8:00 · 점심 12:30 · 저녁 18:30)으로 넣어요. 오늘 칸은 끼니보다 2시간 앞서 열려요: 아침 오전 3시 · 점심 오전 9시 · 저녁 오후 3시부터(그 전에 누르면 알림만).
  - 한 끼니에 한 장: 같은 날 아침 · 점심 · 저녁은 한 장씩. 이미 있는 끼니로 저장하면 바꿀지 묻고, 간식 · 끼니 없음은 여러 장이어도 돼요.
  - 간식은 체크에 들어가지 않고 앨범에서 봐요. 끼니는 찍을 때 스탬프 화면에서 정하고, 남긴 뒤에는 바꿀 수 없어요(사진 보기 제목에 끼니가 붙어요)(아래 줄은 지우기 아이콘 + 사진 교체하기: 새 사진을 고르면 스탬프 화면 없이 같은 날 · 같은 끼니로 바뀌어요).
- **설정**: 앱 열면 바로 카메라 · 즉시 저장(마지막에 쓴 스탬프로) · 사진에 남은 촬영 시각 쓰기 · 셔터 소리·스탬프 효과 · 버전과 새로고침
- **길게 누르기**: 글자는 선택되지 않고 그림에는 아이폰 메뉴가 뜨지 않아요(사진 보기의 큰 사진만 ‘사진 앱에 저장’ 메뉴가 떠요).
- **당겨서 새로고침**: 맨 위에서 당기면 화면이 고무줄처럼 따라 내려오고, 다음 마스코트가 나와요. 놓으면 새 버전까지 받아요. 새로고침해도 보던 탭 · 달 · 위치 그대로예요.
- **마스코트**: 앱을 열 때마다 오둥이와 퍼펭이가 번갈아 나와요.
- **앱 아이콘 · 메인 그림**: PT Note 밝은 바탕에 카메라 든 오둥이 전신(잘림 없이). 같은 그림(오둥이 · 퍼펭이)이 첫 화면과 시작 화면에, 빈 접시 그림이 사진 없는 끼니 · 날에 나와요. 그림 원본은 아스트로가 그렸고(저장소에는 넣지 않음), 아이콘은 `scripts/make-icons.swift`로 만들어요. 달력 도장 · 밥상 캐릭터 · 사진 도장 고리와 원판은 `scripts/make-calendar-art.swift`로 앱 크기에 맞춰요.

## 웹앱이라서 안 되는 것

- **버튼 하나로 사진 앱에 저장하기**와 **사진 앱에 ‘TimeStamp’ 전용 앨범 만들기**는 웹에서는 할 수 없어요. 대신 사진 보기에서 사진을 길게 누르면 아이폰 메뉴의 ‘사진 앱에 저장’으로 공유 화면 없이 바로 저장돼요(‘최근 항목’에 들어가요).

## 파일 구성

```
index.html            화면 구조 (앨범 · 달력 탭, 탭바, 시작 화면, 설정·스탬프·사진 보기 시트, 알림)
styles.css            PT Note 토큰과 컴포넌트 스타일
js/app.js             화면, 설정, 즉시 저장, 스탬프 화면, 달력 칸 넣기 · 바꾸기, 소리·효과
js/stamp.js           스탬프 6종 그리기
js/exif.js            JPEG 촬영 시각 읽기
js/format.js          날짜·시간 표기, 식사 구분
js/db.js              기록 보관 (이 기기의 IndexedDB)
sw.js                 오프라인용 서비스 워커 (네트워크 우선)
manifest.webmanifest  홈 화면 앱 정보
assets/               마스코트, 빈 화면 그림, 앱 아이콘
```

## 실행해 보기

```bash
python3 -m http.server 5173
```

Mac 브라우저에서 http://localhost:5173 을 열어요.

## 배포할 때

GitHub Pages는 파일을 10분씩 캐시하게 해서, 배포 직후 아이폰이 예전 파일과 새 파일을 섞어 쓰면 앱이 깨질 수 있어요. 그래서 배포 전에 버전 숫자를 올려요.

```bash
./scripts/bump-version.sh
```

`index.html`, `js/app.js`, `js/stamp.js`의 `?v=` 숫자와 `sw.js`, `js/app.js`의 버전이 함께 1 올라가요. 그래도 앱이 시작하지 못하면 앱이 스스로 한 번 캐시를 비우고 다시 불러와요. 앱 안에서는 화면을 아래로 당기면 새로고침하면서 새 버전을 받아요.

## 아이폰에서 쓰기

홈 화면 앱과 카메라는 **HTTPS 주소**에서만 동작해요. GitHub Pages, Netlify, Vercel 같은 곳에 이 폴더를 그대로 올리면 돼요.

1. 아이폰 Safari로 배포한 주소를 열어요.
2. 공유 버튼 → **홈 화면에 추가**를 눌러요.
3. 홈 화면의 TimeStamp 아이콘으로 열어요. 홈 화면 앱으로 쓰면 기록이 지워지지 않고 오래 남아요.

기록은 그 아이폰 안에만 저장돼요. 다른 기기와 동기화되지 않아요.
