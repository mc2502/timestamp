# TimeStamp

식단 사진을 찍으면 날짜, 요일, 시각이 스탬프로 함께 찍히고, 그 사진을 트레이너에게 보내는 웹앱이에요.
iPhone 17(402 × 874) 기준으로 만들었고, 디자인은 PT Note 디자인 시스템을 그대로 따라요.

## 할 수 있는 것

- **사진 찍기 / 앨범에서**: 아이폰 기본 카메라나 사진 앨범을 열어요.
- **스탬프**: PT Note 유리 카드 위에 마스코트 얼굴, 식사(아침·점심·저녁·간식), 시각, `2026.11.23 (월)` 형식의 날짜가 찍혀요. 토요일은 파랑, 일요일은 빨강이에요.
- **촬영 시각**: 앨범 사진은 사진에 저장된 촬영 시각(EXIF)을 쓰고, 방금 찍은 사진은 찍은 순간을 써요. 시각이 없으면 지금 시각을 넣고 알려 주며, 직접 고칠 수 있어요.
- **위치**: 음식을 덜 가리는 모서리를 자동으로 골라요. 끌어서 옮기거나 사진의 원하는 곳을 눌러도 되고, ‘자동 위치’로 되돌릴 수 있어요.
- **앨범에 저장 / 보내기**: 아이폰 공유 화면을 열어요. ‘이미지 저장’을 고르면 앨범에, 카카오톡을 고르면 트레이너에게 가요. 원본은 저장하지 않고 스탬프가 찍힌 사진만 남아요.
- **기록 탭**: 저장하거나 보낸 사진을 날짜별로 모아 보여 줘요(앱 안의 전용 앨범). 달력, 끼니별 개수, 다시 보내기, 지우기가 있어요.
- **마스코트**: 앱을 열 때마다 오둥이와 퍼펭이가 번갈아 나와요.

## 웹앱이라서 안 되는 것

- **앨범에 자동으로 저장하기**와 **아이폰 사진 앱에 ‘TimeStamp’ 전용 앨범 만들기**는 웹에서는 할 수 없어요. 저장은 공유 화면에서 한 번 눌러 줘야 하고, 사진은 ‘최근 항목’에 들어가요.
- 전용 앨범이 꼭 필요하면 아이폰 **단축어**로 만들 수 있어요.
  1. 단축어 앱 → 새 단축어 → 이름을 ‘TimeStamp 앨범에 저장’으로 정해요.
  2. 설정(ⓘ)에서 **공유 시트에 보기**를 켜고, 받는 항목을 ‘이미지’로 정해요.
  3. 동작 **사진 앨범에 저장**을 넣고 앨범을 ‘TimeStamp’로 골라요(사진 앱에서 앨범을 먼저 만들어 두세요).
  4. 이제 TimeStamp에서 ‘앨범에 저장’ → 공유 화면에서 이 단축어를 고르면 전용 앨범에 들어가요.

## 파일 구성

```
index.html            화면 구조 (오늘 · 기록 탭, 탭바, 시트 3개)
styles.css            PT Note 토큰과 컴포넌트 스타일
js/app.js             화면, 스탬프 확인 시트, 저장·공유, 기록
js/stamp.js           스탬프 그리기, 자동 위치 고르기
js/exif.js            JPEG 촬영 시각 읽기
js/format.js          날짜·시간 표기, 식사 구분
js/db.js              기록 보관 (이 기기의 IndexedDB)
sw.js                 오프라인용 서비스 워커 (네트워크 우선)
manifest.webmanifest  홈 화면 앱 정보
assets/               마스코트, 빈 화면 그림, 앱 아이콘
```

## 실행해 보기

```bash
python3 -m http.server 5173
```

Mac 브라우저에서 http://localhost:5173 을 열어요.

## 아이폰에서 쓰기

공유 화면(카카오톡, 이미지 저장)과 홈 화면 앱은 **HTTPS 주소**에서만 동작해요. GitHub Pages, Netlify, Vercel 같은 곳에 이 폴더를 그대로 올리면 돼요.

1. 아이폰 Safari로 배포한 주소를 열어요.
2. 공유 버튼 → **홈 화면에 추가**를 눌러요.
3. 홈 화면의 TimeStamp 아이콘으로 열어요. 홈 화면 앱으로 쓰면 기록이 지워지지 않고 오래 남아요.

기록은 그 아이폰 안에만 저장돼요. 다른 기기와 동기화되지 않아요.
