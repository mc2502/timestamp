# TimeStamp

식단 사진에 날짜와 시각을 찍어 남기고, 달력에서 돌아보는 웹앱이에요.
iPhone 17(402 × 874) 기준으로 만들었고, 디자인은 PT Note 디자인 시스템을 그대로 따라요.

## 할 수 있는 것

탭은 **앨범 · (카메라) · 달력** 세 개이고, 설정은 앨범 오른쪽 위 톱니 버튼에 있어요. 가운데 카메라를 누르면 바로 찍고, 길게 누르면 버튼이 톡 튀며 바로 위에 앨범을 든 그날의 캐릭터 버튼이 떠요(손을 뗀 뒤 눌러서 골라요. 아이폰 웹앱은 진동 · 끌어서 놓기로 고르기를 지원하지 않아요).

- **앨범**: 큰 제목 아래 끼니 세그먼트(전체·아침·점심·저녁·간식), 설정. 그 아래 오늘 카드(작은 오둥이 · 퍼펭이 + 지금 끼니 한 줄, 보여 주기만)와 날짜별 3열 사진. 사진을 누르면 크게 보기(사진을 길게 누르면 아이폰 메뉴의 ‘사진 앱에 저장’), 사진 교체하기, 지우기.
- **가운데 카메라 버튼**: 아이폰 기본 카메라가 바로 열려요. 찍어 둔 사진은 카메라 버튼을 길게 누른 뒤 나타나는 캐릭터 버튼으로 골라요.
- **스탬프 화면**: 위는 사진, 아래는 흰 패널 하나. 스크롤 없이 한 화면에 들어와요.
  - 정사각형으로 맞추기: 끌어서 옮기고, 두 손가락으로 키우거나 줄여요. 줄이면 사진 전체가 들어오고 남는 곳은 같은 사진을 흐리게 깔아요. 오른쪽 아래 버튼이나 두 번 톡으로 꽉 채우기 ↔ 사진 전체, ‘원래대로’로 되돌리기
  - 스탬프 7종 + ‘없음’을 작은 그림 타일로 골라요: 오둥이 · 퍼펭이(기본) · 기본 · 캡슐 · 혼합 · 크게 · 필름 · 없음(스탬프 없이 사진만). 칸 크기는 일곱 칸이 한 줄에 맞는 크기 그대로이고, 줄을 옆으로 넘겨 ‘없음’을 골라요 (로고 없음)
  - 오둥이 · 퍼펭이: 왼쪽 아래 모서리에 걸쳐 찍힌 고무 도장(가장자리가 살짝 울퉁불퉁한 원판 + 잉크 고리, 원의 일부는 사진 밖, 날짜 · 시각 · 끼니는 보이는 쪽에), 도장 앞에 살짝 겹쳐 붙은 캐릭터(사진마다 다른 모습). 캐릭터는 끌어서 사진 어디로든 옮길 수 있고, 톡 누르면 다른 포즈, ‘원래대로’면 다시 도장 옆으로
  - 아래 조작부는 줄마다 다른 생김새: 스탬프는 작은 그림 타일 일곱 개 / 식사는 알약 하나(흰 손잡이) / 촬영 시각 ⌄ · 글자색 점은 글자 그대로 / 아래 두 버튼: 앨범 저장(옅은 회색 — 아이폰 공유 화면의 ‘이미지 저장’으로 사진 앱에 넣고 앱에도 남겨요) · 완료(옅은 청색 — 앱에만 남겨요). 위의 X는 남기지 않고 닫아요. 같은 끼니 사진이 이미 있으면 바꿀지 묻고, 취소하면 스탬프 화면에 그대로 있어요. 나중에 사진 앱에 넣고 싶으면 사진 보기에서 사진을 길게 눌러 ‘사진 앱에 저장’.
  - 글자색 흰색 · 하늘색 · 민트(오둥이가 든 책 색) (필름은 주황 고정)
  - 촬영 시각: 사진에 저장된 시각(EXIF)을 먼저 쓰고, 카메라로 바로 찍으면 지금 시각. 앨범 사진에 시각이 없으면 알려 줘요. 눌러서 고칠 수 있어요.
  - 식사: 시간대로 골라 두고, 끼니 이름이 든 막대에서 흰 손잡이를 끌거나 이름을 눌러서 바꿔요(아침 · 점심 · 저녁 · 간식 · 없음). 혼합 스탬프와 캐릭터 도장에 찍히고, 앨범에서 끼니별로 볼 때 써요.
- **달력**: 아침 · 점심 · 저녁 끼니 체크. 스크롤 없이 한 화면에(6주짜리 달도).
  - 달력 칸: 오늘은 점 세 개(남긴 끼니만 하늘색), 세 끼를 다 채운 날은 오둥이 · 퍼펭이 잉크 도장(표정 3종씩, 날짜마다 살짝 기울어 찍힘). 11월 1일부터 어제까지 세 끼를 다 못 채운 날은 회색 ‘못 채운 날’ 도장(오둥이 · 퍼펭이 아쉬움 · 배고픔, 날짜마다 정해진 캐릭터의 두 표정을 번갈아). 위에 이번 달 도장 수와 ‘N일 연속’.
  - 밥상 카드: 고른 날의 캐릭터(빈 그릇 → 마지막으로 먹은 끼니 → 배부름)와 세 칸. 사진이 있으면 체크, 없으면 빈 그릇 그림(지난날은 흐리게). 그림은 그대로이고, 칸을 누르면 빈 칸은 그 날 그 끼니 사진 올리기, 사진 칸은 새 사진으로 바꾸기(누른 순간에만 옅은 테두리). 스탬프 화면 없이 그 칸에 바로 들어가요(스탬프 없이 사진만 · 가운데 정사각형, 있던 사진은 앱에서만 빠짐). 그 날 사진이 아니면 그 날의 끼니 시각(아침 8:00 · 점심 12:30 · 저녁 18:30)으로 넣어요. 오늘 칸은 끼니보다 2시간 앞서 열려요: 아침 오전 3시 · 점심 오전 9시 · 저녁 오후 3시부터(그 전에 누르면 알림만).
  - 한 끼니에 한 장: 같은 날 아침 · 점심 · 저녁은 한 장씩. 이미 있는 끼니로 저장하면 바꿀지 묻고, 간식 · 끼니 없음은 여러 장이어도 돼요.
  - 간식은 체크에 들어가지 않고 앨범에서 봐요. 끼니는 찍을 때 스탬프 화면에서 정하고, 남긴 뒤에는 바꿀 수 없어요(사진 보기 제목에 끼니가 붙어요)(아래 줄은 지우기 아이콘 + 사진 교체하기: 새 사진을 고르면 스탬프 화면이 열려요. 스탬프를 고르고 완료하면 같은 날 · 같은 끼니로 원래 사진 대신 들어가요. 다른 날 사진이면 원래 사진의 시각으로 맞춰요).
- **설정**: 앱 열면 바로 카메라 · 즉시 저장(마지막에 쓴 스탬프로) · 사진에 남은 촬영 시각 쓰기 · 셔터 소리·스탬프 효과 · 백업 파일 만들기/되살리기 · 앱 버전 · 업데이트 노트 · 새로고침
- **길게 누르기**: 글자는 선택되지 않고 그림에는 아이폰 메뉴가 뜨지 않아요(사진 보기의 큰 사진만 ‘사진 앱에 저장’ 메뉴가 떠요).
- **당겨서 새로고침**: 맨 위에서 당기면 화면이 고무줄처럼 따라 내려오고, 다음 마스코트가 나와요. 놓으면 새 버전까지 받아요. 새로고침해도 보던 탭 · 달 · 위치 그대로예요.
- **마스코트**: 앱을 열 때마다 오둥이와 퍼펭이가 번갈아 나와요.
- **앱 아이콘 · 메인 그림**: PT Note 밝은 바탕에 카메라 든 오둥이 전신(잘림 없이). 같은 그림(오둥이 · 퍼펭이)이 첫 화면과 시작 화면에, 빈 접시 그림이 사진 없는 끼니 · 날에 나와요. 그림 원본은 아스트로가 그렸고(저장소에는 넣지 않음), 아이콘은 `scripts/make-icons.swift`로 만들어요. 달력 도장 · 밥상 캐릭터 · 사진 도장 고리와 원판은 `scripts/make-calendar-art.swift`로 앱 크기에 맞춰요.

## 웹앱이라서 안 되는 것

- **버튼 하나로 사진 앱에 저장하기**와 **사진 앱에 ‘TimeStamp’ 전용 앨범 만들기**는 웹에서는 할 수 없어요. 대신 사진 보기에서 사진을 길게 누르면 아이폰 메뉴의 ‘사진 앱에 저장’으로 공유 화면 없이 바로 저장돼요(‘최근 항목’에 들어가요).

## 파일 구성

```
index.html            화면 구조 (앨범 · 달력 탭, 탭바, 시작 화면, 설정·스탬프·사진 보기 시트, 알림)
styles.css            PT Note 토큰과 컴포넌트 스타일
js/app.js             화면, 설정, 즉시 저장, 스탬프 화면, 달력 칸 넣기 · 바꾸기, 소리·효과
js/stamp.js           스탬프 7종 그리기
js/exif.js            JPEG 촬영 시각 읽기
js/format.js          날짜·시간 표기, 식사 구분, 알림 문장 묶음(keepPhrases: 날짜·시각 · ‘남길 수 없어요’ 같은 말이 갈라지지 않게. app.js의 setPhrases가 줄바꿈 없는 칸으로 그린다)
js/db.js              기록 보관 (이 기기의 IndexedDB)
js/album-copy.js      끼니별 오늘 카드 문구
js/releases.js        공개 버전과 업데이트 노트 (최신 항목부터)
js/backup.js          사진 백업 파일 생성·검증
sw.js                 코드·그림 캐시 우선, 첫 화면 2.8초 후 저장본 사용, 그림 내용 지문(ART_HASH)
manifest.webmanifest  홈 화면 앱 정보
assets/               마스코트, 빈 화면 그림, 앱 아이콘
```

## 배포할 때

2026년 11월 26일의 앱을 **1.0.0**으로 정했어요. 이후 업데이트는 `js/releases.js` 맨 위에 새 항목으로 추가해요. 이전 항목은 지우지 않아요. 이 파일이 앱의 **설정 → 업데이트 노트**에 그대로 표시돼요.

1. 작은 수정은 `1.0.1`, 기능 추가는 `1.1.0`처럼 공개 버전을 올려요. 여러 버전을 하나로 합치기로 했을 때만 `RELEASE_MERGE=1 ./scripts/bump-version.sh`로 이전 노트 확인을 건너뛰어요(2026-11-26에 1.0.2–1.0.6을 1.0.2로 합쳤어요).
2. 날짜(한국 기준 `YYYY-MM-DD`), 짧은 제목, 사용자에게 달라지는 점을 `changes`에 적어요. 내부 `build`는 현재 `sw.js`의 번호 + 1이에요.
3. 아래 명령으로 노트를 검사하고 캐시 갱신 번호를 올려요. 노트가 빠지거나 공개 버전을 올리지 않으면 중단돼요.

```bash
./scripts/bump-version.sh
```

`index.html`, `js/app.js`, `js/stamp.js`의 `?v=` 숫자와 `sw.js`의 `VERSION`, `js/app.js`의 `APP_BUILD`가 함께 1 올라가요. 같은 스크립트가 `scripts/art-hashes.mjs`로 `assets/` 그림마다 내용 지문을 `sw.js`의 `ART_HASH`에 적어요. 그래서 같은 파일 이름으로 다시 그린 그림도 설치된 앱이 다음 배포 때 새로 받고, 바뀌지 않은 그림은 다시 받지 않아요. (GitHub Pages의 ETag는 배포마다 모든 파일이 바뀌어서 쓸 수 없어요) 이 내부 번호는 캐시 갱신에만 쓰며 앱에는 **1.0.0** 형식의 공개 버전만 보여요. `node scripts/check-release.mjs`로 현재 배포와 노트가 일치하는지 다시 확인할 수 있어요.

검사 후 변경한 파일만 커밋·푸시하고, 실제 사이트의 설정에서 버전·노트·오프라인 표시를 확인해요. 시작이 늦어도 오프라인 사본을 지우지 않고, 저장·사진 선택·편집 중에는 새 버전 적용을 미뤄요. 새 버전을 찾으면 서비스 워커가 새 버전을 다 받아 자리를 바꾼 뒤에 한 번만 새로 불러와요(느린 망에서 새로고침이 되풀이되지 않게).

## 아이폰에서 쓰기

홈 화면 앱과 카메라는 **HTTPS 주소**에서만 동작해요. GitHub Pages, Netlify, Vercel 같은 곳에 이 폴더를 그대로 올리면 돼요.

1. 아이폰 Safari로 배포한 주소를 열어요.
2. 공유 버튼 → **홈 화면에 추가**를 눌러요.
3. 홈 화면의 TimeStamp 아이콘으로 열어요. 중요한 기록은 설정에서 백업 파일도 따로 보관해 주세요.

기록은 그 아이폰 안에만 저장돼요. 다른 기기와 동기화되지 않아요.


## 저장과 백업

- 완료는 IndexedDB 저장이 성공한 다음 화면을 닫아요. 실패하면 사진과 편집 내용을 유지해 다시 시도할 수 있어요.
- 사진 교체는 새 사진 저장과 기존 사진 삭제가 같은 트랜잭션이에요. 도중에 실패하면 기존 사진이 남아요.
- 설정의 **백업 파일 만들기**로 `.timestamp` 파일 하나를 파일 앱이나 다른 기기에 보관해요. 공유 화면이 바로 열리지 않으면 준비한 파일 저장 버튼을 한 번 더 눌러요.
- **백업에서 되살리기**는 파일 전체의 형식과 사진 해시를 먼저 확인한 다음, 기존 ID나 같은 날 같은 끼니가 없는 사진만 추가해요. 기존 사진을 덮어쓰지 않아요. 백업 파일에는 사진이 그대로 들어 있으므로 개인 파일로 보관해요.
- 새 사진은 최대 1440px, JPEG 품질 0.85로 저장해요. 기존 사진과 예전 원본 파일은 재압축하거나 삭제하지 않아요.
- 자동 끼니: 아침 05–11시, 점심 11–15시, 저녁 17–22시, 나머지는 간식. 스탬프 화면에서 직접 바꿀 수 있어요.
- 편집 화면에서 이미 남긴 끼니를 고르면 기존 사진의 작은 미리보기와 안내가 나타나고, 완료가 **사진 교체**로 바뀌어요. 교체를 취소해도 기존 사진은 그대로예요. 저장·시각 안내는 끼니 아래에 표시해 사진을 가리지 않아요.
- 끼니 막대에는 기록이 있는 칸만 옅은 파란색으로 남아요. 인접한 기록은 색이 이어지고, 현재 선택은 흰 손잡이로 구분해요. 스탬프를 고를 때는 파란 바탕·테두리로 표시하며 사진 속 도장의 농도도 유지해요.
- 서버로 사진을 보내거나 기기 간 자동 동기화하지 않아요. 브라우저 데이터를 지우거나 기기를 바꾸기 전에는 백업해 주세요.
